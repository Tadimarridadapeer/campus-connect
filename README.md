# CAMPUS CONNECT
> **Connecting Every Classroom.**  
> *A Complete Education Management Platform for Schools and Colleges.*

CAMPUS CONNECT is an enterprise-grade, multi-institution education management ERP designed to digitize campus operations across schools, colleges, and polytechnic institutions.

---

## Key Modules & Capabilities

1. **Multi-Tenant Architecture**: Logical isolation for multiple campuses (*Greenfield International School*, *Bright Future Public School*, *Horizon Degree College*) with unified Super Admin governance.
2. **Student 360° Lifecycle**: Full registry, 14-attribute dossier, printable student ID cards, bulk promotions, and CSV import/export.
3. **Faculty & Staff Directory**: Workload schedules, department assignments, and employee profiles.
4. **Conflict-Free Timetabling**: Real-time clash detection engine preventing teacher double-booking and room conflicts.
5. **Attendance Intelligence**: Fast daily roll-calls (Present, Absent, Late, Leave), automated percentage calculations, and SMS alerts simulation.
6. **Curriculum Tracking & Daily Teaching Logs**: Milestone syllabus tracking with learning outcomes and verified daily classroom logs (*Key Differentiator*).
7. **Examinations & Report Cards**: Automated marks matrices, CBSE 9-point & UGC 10-point GPA grading scales, and printable official report cards.
8. **Multi-Head Fee Engine**: Tuition, transport, and lab fee heads, overdue tracking, simulated online payment gateway, and serialized receipts.
9. **Homework & Digital Submissions**: Assignment creation, digital attachment downloads, student turn-in, and rubric-based evaluation.
10. **Official Document Registry**: One-click generation of Bonafide, Study, Transfer (TC), and Character certificates.
11. **Campus Notice Board**: Internal bulletins with priority levels and audience targeting.
12. **Analytics & Reports**: Visual enrollment, financial realization, and performance charts with exportable CSVs.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Engine**: React 19, Tailwind CSS 4 (`@tailwindcss/turbopack`)
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **Language**: TypeScript 5

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Start production server:
   ```bash
   npm start
   ```
